# Budget Limits Design

**Дата:** 2026-01-30
**Статус:** Утверждён
**Iteration:** 12

## Обзор

Добавление функционала бюджетных лимитов по категориям. Пользователь устанавливает месячный лимит на категорию, при превышении получает уведомление.

## Принятые решения

| Вопрос | Решение |
|--------|---------|
| Хранение лимитов | Отдельный лист "Лимиты" в Google Sheets |
| Период лимита | Только месяц |
| Уведомления | Только при превышении (>100%) |
| Установка лимитов | Команда `/limit` |
| Отображение | Интегрировать в `/stats` |

## Структура хранения

### Новый лист "Лимиты" в Google Sheets

| Категория | Лимит |
|-----------|-------|
| Еда | 10000 |
| Транспорт | 5000 |
| Продукты | 15000 |

- Только 2 колонки (период всегда месяц)
- Категория должна совпадать с `CATEGORY_EMOJI`
- Пустая строка или 0 = лимит не установлен
- Пользователь может редактировать прямо в Sheets

## Команда /limit

### Синтаксис

```
/limit                      — показать все лимиты
/limit Еда 10000           — установить лимит
/limit Еда 0               — удалить лимит
```

### Форматирование вывода

```
📊 Ваши лимиты на месяц:

🍔 Еда: 10 000₽
🚗 Транспорт: 5 000₽
🛒 Продукты: 15 000₽

Изменить: /limit Категория Сумма
Удалить: /limit Категория 0
```

### Валидация

- Категория должна существовать в `CATEGORY_EMOJI`
- Сумма должна быть числом ≥ 0
- При ошибке — понятное сообщение

## Уведомления при превышении

### Когда проверять

- После каждого добавления расхода
- Проверяем только категорию добавленного расхода

### Логика

1. Получить лимит для этой категории
2. Если лимит не установлен → ничего не делать
3. Получить сумму расходов за текущий месяц по этой категории
4. Если сумма > лимит → добавить предупреждение

### Формат предупреждения

Обычный ответ:
```
✅ Расход добавлен!

📝 Категория: 🍔 Еда
💰 Сумма: 500₽
📅 Дата: 30.01.2026
```

С предупреждением:
```
✅ Расход добавлен!

📝 Категория: 🍔 Еда
💰 Сумма: 500₽
📅 Дата: 30.01.2026

⚠️ Лимит по Еда превышен: 10 500 / 10 000₽
```

### Реализация

- Проверка в MCP Service
- Возвращаем `limit_exceeded: {category, spent, limit}` в ответе
- Бот форматирует предупреждение

## Интеграция в /stats

### Новый формат (для месячной статистики)

```
📊 Статистика за месяц

🍔 Еда: 8 000 / 10 000₽ ████████░░ 80%
🚗 Транспорт: 3 000 / 5 000₽ ██████░░░░ 60%
🛒 Продукты: 14 000₽ (без лимита)

💰 Итого: 25 000₽
```

### При превышении

```
🚗 Транспорт: 7 500 / 5 000₽ ██████████ 150% ⚠️
```

### Логика

- Прогресс-бар показывает % от лимита (не от общей суммы)
- Если лимита нет — показываем только сумму без процентов
- При превышении (>100%) — добавляем ⚠️
- Лимиты показываются только при `period=month`
