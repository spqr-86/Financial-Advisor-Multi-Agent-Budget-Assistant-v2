# Statistics Redesign

**Дата:** 2026-01-31
**Статус:** Approved

## Цель

Переработать функционал статистики: убрать лишнее, добавить гибкий выбор периода и фильтрацию по категории.

## Изменения

### Убираем
- Кнопку "Год" из выбора периода
- Прогресс-бары из статистики за неделю

### Добавляем
- Выбор месяца (текущий + 3 прошлых)
- Команду `/stats` с аргументами: `/stats еда`, `/stats январь`
- Детализацию по категории (список трат)
- Пагинацию "Показать ещё"

## Точки входа

### Команда `/stats`

```
/stats              → показывает кнопки выбора периода
/stats неделя       → статистика за неделю (без прогресс-бара)
/stats январь       → статистика за январь 2026
/stats еда          → детализация трат на еду (текущий месяц)
/stats еда январь   → детализация трат на еду за январь
```

### Текстом через AI

- "статистика" → кнопки выбора
- "статистика за неделю" → сразу результат
- "траты на еду" → детализация еды
- "сколько потратил на транспорт в декабре" → детализация

## Формат вывода

### Статистика за неделю (без прогресс-бара)

```
📊 Статистика за неделю

🍕 Еда: 3,500₽
🚗 Транспорт: 1,200₽
🎮 Развлечения: 800₽

💰 Итого: 5,500₽
```

### Статистика за месяц (с прогресс-барами от лимитов)

```
📊 Статистика за январь 2026

🍕 Еда: 8,000 / 10,000₽ ████████░░ 80%
🚗 Транспорт: 3,500₽
🎮 Развлечения: 2,000₽

💰 Итого: 13,500₽
```

Прогресс-бар показывается только для категорий с установленным лимитом.

### Детализация по категории

```
🍕 Еда за январь 2026

1️⃣ 28.01 | Обед в кафе — 450₽
2️⃣ 27.01 | Продукты Пятёрочка — 1,200₽
3️⃣ 25.01 | Кофе — 150₽
4️⃣ 24.01 | Доставка суши — 980₽
5️⃣ 22.01 | Продукты — 2,300₽

💰 Итого: 5,080₽ (10 записей)
```

- Показывает последние 10 трат в категории
- Сортировка по дате (новые сверху)
- Если трат больше — внизу "(показано 10 из 25)"

## Кнопки

### После `/stats` (выбор периода)

```
[ 📅 Неделя ] [ 📅 Январь 2026 ]
[ Декабрь ] [ Ноябрь ] [ Октябрь ]
```

### После статистики за период

```
[ 🔙 Выбрать период ]
```

### После детализации категории (если есть ещё записи)

```
[ ⬇️ Показать ещё ] [ 🔙 Назад ]
```

### После детализации (все записи показаны)

```
[ 🔙 Назад ]
```
